# Historical Past Events

Papers on data-driven retrodiction of past states and events using alternative-history maps, uncertainty-aware smoothing, and causal memory.

[Back to the main README](../README.md)

## Papers

### [Data-Driven Retrodiction with Red-String Maps and Causal Memory](Retrodiction_Red_String_and_Causal_Memory.pdf)

Reconstructs missing past states or events from later observations using learned relationships, complete alternative-history branches, and uncertainty-aware smoothing. Independently measured delayed responses can distinguish some candidate pasts; observationally equivalent histories remain unresolved.
