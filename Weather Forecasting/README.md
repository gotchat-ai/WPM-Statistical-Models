# Weather Forecasting

Papers on transferring weather predictors across locations and regimes using aligned observations, targets, and compatibility checks.

[Back to the main README](../README.md)

## Papers

### [Cross-Family and Partial-Family Weather Prediction](Cross_Family_Weather_Prediction.pdf)

Develops source-trained weather transfer through aligned observations, seasonal coordinates, targets, and horizons. A constructed California-Florida example explains support checks, partial compatibility, and why transferring a rain predictor differs from predicting another weather variable using rain alone.
