# AI System

Papers on data-driven prediction of AI-training progress, structural transitions, oscillation, instability, plateaus, failure, and optimization response.

[Back to the main README](../README.md)

## Papers

These papers apply WPM to observed AI-training histories, with separate definitions and models for each prediction target.

### [WPM for AI-System Prediction](AI_System_Prediction_Overview.pdf)

Introduces the monitoring workflow for future progress, variability, structural transitions, oscillation, instability, plateaus, and failure. It addresses observation cutoffs, future schedules, censoring, interventions, and transfer between AI systems.

### [Structural Transition Prediction](AI_Structural_Transition_Prediction.pdf)

Forecasts changes in measured training descriptors using location, scale, and resolution landscapes. It distinguishes structural change from failure or improvement in model quality.

### [Oscillation Prediction](AI_Oscillation_Prediction.pdf)

Predicts a declared increment-sign-reversal event, accounting for observable choice, noise, sampling, and probability calibration. It distinguishes operational reversals from physical periodicity and parameter oscillation.

### [Instability Prediction](AI_Instability_Prediction.pdf)

Defines gradient-excursion and rolling-range events, separating endpoint exceedance from first-entry risk. It explains when direct telemetry is valuable and why unforeseen shocks limit advance warning.

### [Plateau Transition Prediction](AI_Plateau_Transition_Prediction.pdf)

Forecasts entry into a defined low-progress, low-variability morphology, with recognition gates and persistence rules. It separates future entry from an existing plateau and plateau behavior from successful optimization.

### [Foreseeable Failure Prediction](AI_Foreseeable_Failure_Prediction.pdf)

Models entry into an independently defined failure region under a stated continuation policy. Location-scale uncertainty, hazards, path uncertainty, and warning costs explain why a safe predicted mean can still carry failure risk.

### [Optimization Response Prediction](AI_Optimization_Response_Prediction.pdf)

Uses observed n/s descriptors to forecast future cross-scale response magnitude. It separates response from useful loss improvement, moment-order extrapolation from temporal forecasting, and observed-policy prediction from causal intervention effects.
